KO TECH - NETLIFY DRAG-AND-DROP EDITION
======================================

WHAT TO UPLOAD
- This ZIP has index.html at its root and is intended to be EXTRACTED first.
- Extract the ZIP on your computer. Then open https://app.netlify.com/drop
- DRAG THE EXTRACTED "KO-TECH-Netlify-Deploy" FOLDER onto Netlify Drop.
- Do not drag the ZIP itself or the original nested project folder.
- You can edit the HTML, JS and CSS locally using Visual Studio Code.

NETLIFY FORMS (CONTACT + ENQUIRY)
- In your Netlify site's dashboard, open Forms and enable form detection.
- Deploy this folder again AFTER enabling form detection if requested.
- The form definitions are in netlify-forms.html and submit via AJAX.
- Netlify receives entries under Forms; email alerts must be configured in Netlify.
- Test by submitting both forms on your new netlify.app website.

FEATURES AVAILABLE ON NETLIFY WITHOUT A SERVER
- Homepage, all images, responsive navigation, gallery/lightbox, map.
- Product catalogue, search, filtering, details and deals.
- Shopping bag, wishlist and discount calculation stored locally on this browser.
- Demo checkout, PDF order slips and local demo-order tracking.
- Contact and enquiry submissions once Netlify Forms has been enabled.

IMPORTANT LIMITATIONS
- This is an educational/storefront demonstration. No money is collected.
- Demo checkout DOES NOT submit an order to a merchant; no real fulfilment.
- Demo orders are available ONLY in the browser that placed them.
- Login, register, recovery, shared orders, reviews and the admin dashboard
  need the ORIGINAL Node.js backend with persistent storage and are not live here.
- Do not enter real card details or treat demo orders as confirmed purchases.
- Use a proper hosted backend for real accounts, orders and administration.

Original academic reference and rubric files are retained separately in your
original uploaded project. Keep a copy of the original zip for the full backend.
